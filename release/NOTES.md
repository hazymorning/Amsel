# Leaf litter

## New

- **Updates in one tap:** Install update downloads the new version and opens Android's installer; the first time, Android asks to let Amsel install apps.
- **Speaker in the bar:** the speaker button sits in the bottom bar, with a moss dot while music plays.
- **Home:** each section's title can be hidden in Edit Home.
- **Settings:** a blackbird rises at the foot of Settings.

## Better

- **Covers:** an artist without a picture wears its albums' covers; anything else without one shows a large, faint letter.
- **Battery:** Amsel rests its connection when nothing plays, sends audiobook progress less often and builds the search index only in Search.
- **Security:** your token goes only to your own Music Assistant, plain http only to your home network, and downloads stay in their folder; only the real Android Auto counts as a car.

## Fixed

- **Audiobooks:** switching from one downloaded book to another no longer loses the first one's place.
