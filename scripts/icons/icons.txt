# Phosphor icons, copied in as vector drawables by scripts/icons/fetch-icons.py. Each comes in the
# Regular, Bold and Light cuts, whose lines are 1.5 dp at 24, 16 and 32 dp; the app draws the cut
# whose line is nearest 1.5 dp at the size it is drawn. One icon per line:
#   <drawable name, written as ic_<name>.xml>  <phosphor icon>  [fill|bold]  [mirrored]  [custom]
#   [heavy]  [stroke:<units>]
# "fill" (transport glyphs and the selected tab) and "bold" (three dots, which have no line to
# keep) come in that one cut only.
# "heavy" adds a cut with a 32 unit line, 1.5 dp at 12 dp, for a glyph inside a download's ring.
# "stroke:<units>" draws Phosphor's own line drawing with lines that wide, in one cut: the caret
# after words is a step smaller than they are, and 29 units keep its line at 1.5 dp there.
# "mirrored" flips the glyph in right-to-left layouts (arrows and lists that point somewhere).
# "custom" takes scripts/icons/custom/<icon>.svg instead: Amsel's own glyphs, drawn to Phosphor's
# spec (a 16 unit stroke on its 256 grid, round ends), in the same three cuts.
# Run scripts/icons/fetch-icons.py after editing; icons that leave this list are deleted.
