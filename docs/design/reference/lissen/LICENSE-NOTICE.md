# Lissen reference screenshots

The six images in this folder (`1.png` to `6.png`) are the Google Play / F-Droid store
screenshots of **Lissen**, an Audiobookshelf client for Android by Max Grakov
(<https://github.com/GrakovNe/lissen-android>). They were copied unchanged from
`metadata/en-US/images/phoneScreenshots/` at commit `421288498f429f4c438528490807de86ec59f382`
(1 November 2026).

They are **design reference images only**. Amsel's design critic and its builders compare
Amsel's screens against them (see `docs/DESIGN.md`).
They are never packaged into the app, never shipped in an APK or release, and nothing in Amsel's
code is derived from them.

| File | Shows |
| --- | --- |
| `1.png` | Library: "Continue listening" carousel, then the book list |
| `2.png` | Player: artwork, title, seek bar, transport, chapter list, bottom actions |
| `3.png` | Connection preferences (a settings sub-screen) |
| `4.png` | Downloads list with one item expanded |
| `5.png` | Player with the Bookmarks sheet open |
| `6.png` | Player with the Sleep timer sheet open |
